# banco_de_dados

Repositório das atividades da disciplina de Banco de Dados.
Cada atividade fica em sua própria pasta, com a modelagem e os scripts SQL.

## Atividades

| Atividade | Tema | Vencimento | Pasta |
|---|---|---|---|
| Atividade completa banco de dados | Controle de Inventário de Laboratórios — modelagem, DDL e DML (INSERT, SELECT com JOIN, UPDATE, DELETE) | 28/05/2026 | [`atividade-inventario-laboratorios/`](atividade-inventario-laboratorios/) |
| Tarefa 1 | Modelo conceitual, lógico e físico + carga inicial dos dados oficiais — Laboratório Prático: SQL DML Avançado (Especial Copa do Mundo) | 11/06/2026 | [`tarefa-01-modelagem/`](tarefa-01-modelagem/) |

## Ambiente

Os scripts SQL são escritos para **PostgreSQL 16** e foram testados nessa versão.
Cada atividade traz no seu próprio `README.md` as instruções de execução e as
adaptações necessárias para outros SGBDs.
